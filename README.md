## 📖 About Project

**User Search App** adalah aplikasi Android native yang dibangun menggunakan bahasa **Kotlin**. Aplikasi ini memungkinkan pengguna untuk mencari akun User (Seperti Instagram), melihat profil detail, daftar followers & following, hingga mengatur tema aplikasi (Light/Dark Mode).

Project ini dibuat sebagai bagian dari submission pada program **Bangkit Academy**.

---

## 🚀 Features

- 🔍 **User Search**: Mencari pengguna secara real-time.
- 👤 **Detail Profile**: Menampilkan avatar, nama, username, serta data statistik pengguna.
- 👥 **Followers & Following**: Menampilkan daftar pengikut dan yang diikuti menggunakan `ViewPager2` dan `Fragment`.
- 🌙 **Theme Switcher**: Fitur ubah tema Dark/Light Mode menggunakan **DataStore Preferences**.

---

## 🛠️ Tech Stack & Libraries

- **Language**: [Kotlin](https://kotlinlang.org/)
- **UI Architecture**: MVVM (Model-View-ViewModel)
- **UI Components**: ViewBinding, RecyclerView, Fragment, ViewPager2
- **Async & Lifecycle**: LiveData, ViewModel
- **Local Storage**: DataStore Preferences
- **Networking**: Retrofit, Gson, OkHttp
